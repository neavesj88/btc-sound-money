How this works · data sources · caching

BTC price history comes from Kraken's public OHLC API (no key required) — daily candles, up to 720 per call. Longer ranges fire parallel requests that are merged and deduplicated. AUD values are derived by multiplying BTC/USD by USD→AUD from Frankfurter (ECB reference rates, free, no key). Gold/oz comes from freegoldapi.com (USD daily history, no key). Gram price = oz ÷ 31.1034768.

CPI-adjusted lines re-express historical USD or AUD in today's purchasing power using long-run inflation rates (USD ≈ 3.2%/y, AUD ≈ 3.0%/y as a rolling average). It's a smoothed reference, not month-exact CPI.

The "% Change" view is the best one for comparing growth rates across all units — it shows BTC's gain vs gold's vs M2's expansion on a single axis from the same starting point.

All API responses are cached in localStorage for 6 hours, keyed by range. Once loaded the page works offline. To force-refresh, hit Shift+reload or clear site data.

Everything runs client-side. No tracking, no key. Save this file anywhere and it works.
